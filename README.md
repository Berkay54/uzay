# Ne Kadar Uzak?

Çıplak gözle ne kadar uzağı görebilirsin? Gözün içinden başlayıp 2,5 milyon ışık yılı ötedeki Andromeda'ya uzanan, scroll ile ilerleyen bir yolculuk.

- Hero: kaydırmaya bağlı kare kare oynatılan video (canvas + WebP kare dizisi)
- Ay'dan Andromeda'ya yedi durak, logaritmik uzaklık cetveli
- Vite, GSAP ScrollTrigger, Lenis

## Çalıştırma

```bash
npm install
npm run dev
```
